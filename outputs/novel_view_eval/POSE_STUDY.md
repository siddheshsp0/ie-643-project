# Pose study: which camera move gives the sound room to act?

Generated by `scripts/compare_pose_study.py v1 v2_noforward v2_rotonly v2_focal200 v2_yaw20`. Same 8 S4 test scenes, 4 sounds (cat, dog, baby, guitar) and seeds 0, 1 in every run, so the runs differ only in the warp. Each cell has 64 audio images (8 scenes × 4 sounds × 2 seeds; runs with more seeds are restricted to the shared ones). Hit = CLIP top-1 on the generated pixels is the sound's class. The 95% interval bootstraps over scenes.

Hole columns are fractions of the 512×512 view. **frame** = holes touching the border (the band that rotates into view). **interior** = disocclusions behind near objects. **roomy** = hole pixels more than 32 px from any seen pixel (room for a 64 px object).

**Δ vs v1** = paired difference in audio top-1 over the same scenes, against v1 at the same yaw (or the same direction, e.g. +20° vs +15°); points, 95% CI over scenes.
